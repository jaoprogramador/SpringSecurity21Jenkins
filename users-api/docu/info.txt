1.- crear microservicio http://localhost:8080/api/users
2.- clen install
3.- crear un contenedor de mysql BD
	docker run -d --name mysqldbUSERS -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=mysqldbUSERS -p 3305:3306 mysql:8.1
4.- crear en el contenedor la bd:(entrar contenedor y crear bd)
		docker exec -it mysqldbUSERS mysql -u root -p
		
		CREATE DATABASE mysqldbUSERS;
		EXIT;
5.- arrancar microservicio y probarlo en localhost:8080/api/users
6.- Instalamos minikube desde powerShelADMIN: 
	curl.exe -Lo minikube.exe https://storage.googleapis.com/minikube/releases/latest/minikube-windows-amd64.exe
	Lanzamos minicube start en el cmd
6.- dockerizar con una imagen la api despues de crear el dockerfile o imagen
	docker build -t users-api:3.5.6 .
	
7.-creamos un fichero de servicio a BD para desplegar en kubernetes
8.- arrancamos minikube: minikube start
9.- contruimos el servicio de bd en kubernetes
	kubectl apply -f k8s/mysql-init-configmap.yaml
	kubectl apply -f k8s/db-deployment.yaml 
10.- consultamos que se ha deployado bien 
	crear mysql-deployment.yaml archivo de configuración de Kubernetes que define cómo debe ejecutarse tu base de datos MySQL dentro del clúster de Minikube
11.- Crear una imagen de docker del api users
	docker build -t spring-users-api-k8s:1.0 .
	
12.- creamos un fichero para desplegar el servicio del api spring en k8s
	kubectl apply -f k8s/app-deployment.yaml 
13.-cargamos la imagen en minikube
	minikube image load spring-users-api-k8s:1.0
14.- kubectl get deployments
	kubectl get pods
	kubectl logs NAME_PODS PARA VER LOS LOGS DEL POD O INSTANCIA
